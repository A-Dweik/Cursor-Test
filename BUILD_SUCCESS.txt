   npm install

2. بناء Frontend (تم بالفعل):
   npm run build

3. استعادة وبناء Backend:
   dotnet restore
   dotnet build

4. تشغيل التطبيق:
   dotnet run

5. الوصول إلى التطبيق:
   http://localhost:5010/applications/cowbusiness/

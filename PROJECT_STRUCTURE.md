## How to Run

### Prerequisites
- Node.js (v12+)
- .NET Core SDK 3.1
- npm

### Steps
1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Build frontend**:
   ```bash
   npm run build
   ```

3. **Restore .NET packages**:
   ```bash
   dotnet restore
   ```

4. **Build backend**:
   ```bash
   dotnet build
   ```

5. **Run application**:
   ```bash
   dotnet run
   ```

6. **Access application**:
   ```
   http://localhost:5003/applications/weathergerman/
   ```

## Weather Data

### Data Source
- **API**: Open-Meteo (https://open-meteo.com/)
- **Cost**: Free (no API key required)
- **Features**: Current weather + 7-day forecast
- **Timezone**: Europe/Berlin (CET/CEST)

### Data Points
- Temperature (°C)
- Wind speed (km/h)
- Weather condition (with Arabic description)
- Precipitation (mm)
- Min/Max temperatures
- Weather codes (WMO standard)
